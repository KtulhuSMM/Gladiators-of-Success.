# Локальные макеты «Гладиаторов успеха»

Эта папка не опубликована в GitHub, пока не будет готов полный печатный
комплект.

- `cover-front.html` — лицевая сторона с точной русской типографикой;
- `cover-wrap.html` — полноразворотная обложка A5 с задником, корешком и вылетами 3 мм;
- `../cover-artwork-v1.png` — иллюстрация для макета.

Визуальный принцип: современная драматургия темы статуса и публичного успеха
с академически сдержанным набором. Название издательства СПбДА, его логотип,
гриф, ISBN, УДК и ББК в макет не включены: право их использовать появляется
только после решения издателя и получения реальных данных.

`cover-wrap.html` использует временный корешок 2 мм; это макетное значение, а
не технический расчёт. Для тиража его заменяют по шаблону типографии после
выбора бумаги и переплёта. Текущая иллюстрация — дизайнерская версия для
согласования. Для типографии потребуется исходник фоновой иллюстрации в
требуемом разрешении.
